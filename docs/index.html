FATHOM

Helpful. Not omniscient. · Hear it

Every file is the real thing: the original Subnautica PDA voice, IVONA Amy through the original filter chain. Model lines were written live by a local model held to the PDA's register. Template lines play instantly from the cache. Pooled lines are the plain readouts for the quiet minutes. Headphones. Lights off.
